# Judgement: the seller profile and choosing the lens

Part of the judgement rules (`judgement.md` is the core). Read when there is a profile or it is to be offered. With a profile, once the lens is chosen, read `judgement-for-you.md` and that lens's file only (`judgement-lens-cold-traffic.md`, `judgement-lens-marketplace.md`, `judgement-lens-own-stock.md`, `judgement-lens-maker.md` or `judgement-lens-general.md`; plus `judgement-lens-goals.md` when the goal is set).

## The seller profile and lenses

The facts table and the market verdict are the same for everyone. What changes with the user is **which facts count** and **the decision**: a heated eye mask can be Strong for the market, a strong fit for a seller with USD 5k of own stock, and a fit, with one fix, for a first-timer dropshipping on cold traffic until a supplier read shows single units ship. The profile is how Claude knows which.

### The profile

Asked early, remembered, re-checked when it may be stale.

**Five quick bands, friendly, skippable:**

> So I can say what this means for you, 5 quick ones (skip any): roughly what could you put into a first order, or a first month of ads if you'd dropship (under $250, under $1k, $1k–5k, $5k–25k, more)? How would you fulfil (dropship, own stock, Amazon FBA, print on demand)? Sold online before (no, a bit, yes with a brand)? Any channels already (a store, Amazon, TikTok, an email list, none)? And is this a side income or a brand you want to build?

**Fulfilment options, in plain words** (in the guided session, for a newcomer, or when asked what one means), a few words each, after the question: **dropship** (a supplier ships each order straight to your buyer; you hold no stock), **own stock** (you buy units up front and ship orders yourself), **Amazon FBA** (you send stock to Amazon's warehouses and Amazon ships each order), **print on demand** (a printer makes and ships each item only when it sells, with your design on it), **I make it myself** (you make each item by hand or in your own workshop).

**A sixth fulfilment option, "I make it myself."** Wherever the five bands are asked, the fulfilment question offers it after print on demand: "How would you fulfil (dropship, own stock, Amazon FBA, print on demand, or I make it myself)?" It is the Maker lens ("Choosing the lens").

**Asking for the profile: once per conversation.** This is the one rule every skill follows:
- **Offered once,** in the first message that needs it: the guided session's opening (`running.md`, "First use"), or the cost line of the first judgement (or the message that says the runs have started), so nothing waits on it. Only when no such message came before the first answer (a run that went ahead without a yes) does the first answer's first screen carry it, in one friendly line ("Answer structure").
- **A quick one-off read** (one read under about USD 0.10; it still waits for a yes when it is over USD 0.05, as every run does: `running.md`, "Before any run") goes ahead first, with no profile in its cost line, and the profile is offered after its answer, in that answer's one friendly line; that is still the one offer for this conversation.
- **Skipped or unanswered, never again in this chat:** no re-offer in later answers, follow-ups or other skills. The market verdict leads from then on.
- **One exception:** if the user later asks something personal ("is this right for me?", "could I afford it?"), one line may remind them the five bands would answer it; it is a reminder, not the question again.
- A profile they give later, unprompted, is used at once ("Accept it unprompted").

**Accept it unprompted.** If the user says "I've got about $2k and I've never sold before" anywhere in the chat, the conversation holds a line starting `Profile:`, or their notebook holds a profile (`notebook.md`), use it. Repeat it back once as bands ("Judging for: $1k–5k · own stock · first time · no channels · side income · US") and move on.

**When the question and the profile disagree,** the newer, more specific statement wins: a budget, a channel or a way of fulfilling named in this question (or later in this chat) beats the saved or earlier profile, for this answer. Say so in one line, as bands, before the verdict: "Your profile says under $1k, but you mentioned a bigger amount for this one, so I judged it at $1k–5k." · "Your profile says Amazon FBA, but you said this one would sell through TikTok ads, so I read it through the cold-traffic dropship lens." Never ask which one is right first, and never repeat the exact figure (bands only, as below). When the change sounds lasting rather than about this one idea ("I've moved to FBA", "I've saved more now"), the stale re-check line below offers to save it; otherwise the saved profile stays as it is.

**Remembered, with the user's yes.** When the user gives a profile and has opted in to the notebook in this chat (or a notebook was read here), save it with `upsertProfile` (bands only: `notebook.md`). If they haven't been asked about the notebook yet, the one notebook line (`notebook.md`, "Ask once") mentions that it keeps their profile too. If they'd rather not, give them the `Profile:` line to keep.

**Re-checked when it may be stale,** at most once per chat, in one line and never blocking a run: when the profile came from the notebook and its newest entry is 30 days old or more, or when something the user says doesn't fit a band ("I've just placed my first order", "I've moved to FBA"). "Still around $1k–5k and dropshipping?" A change is saved with `upsertProfile` (only the changed fields).

**"I make it myself."** A user who says they make what they sell ("I'm a potter", "I make candles", "handmade", "I make them") has `fulfilment` maker, whether or not they picked it from the list, and gets the Maker lens. A budget band, if they give one, is information for them (materials and tools), never a first-order gate. Notebook 0.2 accepts `fulfilment: "maker"`, so the note in the rest of this sentence applies only to an older notebook (before 0.2): the notebook can't hold maker yet: the profile is saved without `fulfilment` (the rest as bands), and the save line says so once ("the notebook can't keep 'I make it myself' yet, so tell me again next time and I'll read it through the maker lens"); never saved as own stock. Since notebook 0.2 it can: `fulfilment: "maker"` is saved like any other band, with no such line; the line above is only for a save that leaves `fulfilment` out (an older notebook build, or a `warnings` entry naming it: `notebook-use.md`, "A maker's profile").

**Where they sell from, when it differs from the marketplace.** Asked only when the user names a country they live or sell from that differs from the marketplace's ("I'm in Lagos, selling on amazon.com", "from Shenzhen", "a student in Kenya wanting to sell in the US"), and never otherwise: one optional line, once per conversation, in the message with the cost line, skippable, nothing waiting on it: "Where are you selling from? It changes which channels you can open and what the first steps are." **Never asked when they already named it:** a country they said they live or sell from in this chat ("I'm in Lagos", "a potter in Vancouver", "from Shenzhen") is their answer, used at once with no question, and said back once in the bands line ("… · selling from Nigeria"). The question is asked only when they hint they are abroad without naming where ("I'm not in the US", "selling from overseas"). Their answer (a country, kept for this chat only and never saved: the notebook's `marketCountry` stays the marketplace's) sets:
- **the channels named as theirs to open:** a channel that may accept sellers only from some countries (TikTok Shop US, Shopify Payments) is named as a check, never as a lead ranked for them: "TikTok Shop US and Shopify Payments accept sellers from some countries only: check their sign-up pages for yours before counting on them"; the reads still run, and a channel they can't open is said as context, not a fix;
- **a cross-border first-steps note,** one short list after the answer, each a step to check, never a rule from memory: the marketplace's seller registration (whether it accepts sellers based in their country, and what it asks for), how payouts reach them (a payout account that accepts the marketplace's currency), shipping stock into the marketplace's country (a freight forwarder, the importer of record and duty, FBA's inbound rules), and the marketplace country's product rules (the risk notes). One line: "These are what to check; the marketplace's seller help for your country gives the exact rules."
- Say once that MarketMage works from anywhere: "It reads the marketplaces where you sell, wherever you're based: sellers in Nigeria, China, Brazil or anywhere outside the US and EU use the same reads, prices and caps."

**Fields, as bands only:** `budgetBand`, `fulfilment`, `experience`, `channels`, `goal`, and `marketCountry` (already known from the marketplace). If the user volunteers them: `skills` (ads, content, sourcing, design) and `timePerWeek`. A price range the user gives ("under $30") is used in the chat for the search and the price gate, never stored. Never ask for revenue, margins, supplier names or quotes, product names, account details, the business entity, or anything about a named person.

**Privacy, unchanged:**
- It goes to Apify only through the notebook, as bands, after the user's yes (`notebook.md`): never in a task, any other run's input, a dataset or a key-value store.
- Exact money figures are turned into a band before use; the exact figure is never repeated or stored, not even in the "For you" prose ("your band covers the first order", not "your USD 400 covers it"). A fit check uses the band's edges ("under $1k").
- **An exact amount given in this chat** ("I've saved about $600") is also kept, privately, for this chat's fit check: the first order (for a dropshipper, the sample order and the first month's test ads) is checked against **that amount**, not the band's upper edge, with room left for freight, samples, fees and launch ads, and the line says "fits the amount you gave me" or "doesn't fit the amount you gave me", never the figure (`judgement-lens-own-stock.md`, "Against the amount you gave me"; `launch-plan` plans its first order the same way, so the two agree). The amount is never stored, saved to the notebook or put in any run's input; a later chat without it uses the band.
- **Under $250** is the lowest band, a narrower answer inside under $1k for someone starting very small. Every rule and table that lists "under $1k" (choosing the lens, the Where you'd compete reading) reads it as under $1k, except the fit check's edge (USD 250), the first-order gate's wording in this chat, which names the band they picked ("within your up-to-$250 budget" when it passes, "over your up-to-$250 budget" when it fails, never "under-$1k" for them), and `launch-plan`'s goods and test-spend rows, which have their own. The notebook's lowest band is `under-1k`: under $250 is saved as `under-1k`, and the save line says so once ("saved as under $1k, the notebook's lowest band").

### Choosing the lens

One **fulfilment lens**, chosen from `fulfilment` **and** `channels` (where this product would sell), plus a **goal lens** when the goal is set. Say the lens once, in the "For you" heading ("For you, through the cold-traffic dropship lens"). Every profile gets a lens, so a "For you" verdict always exists.

| Profile | Lens |
| --- | --- |
| `fulfilment` dropship or print on demand, selling through ads, their own store or TikTok (`channels` store, social, tiktok; or they name ads); or `fulfilment` dropship with `channels` none | **Cold-traffic dropship** (print on demand: gate 2 doesn't apply, it is made to order; gate 3 uses the print-on-demand base cost only when the user or a read gives it, else the cost-free floor applies (gate 3's ordered steps: step 2 can fail it, step 1b can make the price the fix), and otherwise it is unclear as a note, never a cap) |
| `fulfilment` dropship or print on demand, selling on Amazon, Etsy or eBay (search-led marketplaces) | **Marketplace** |
| `fulfilment` own stock or FBA | **Own stock / FBA** (at $1k–5k and under $1k the first-order gate decides more often) |
| `fulfilment` maker ("I make it myself": handmade, small-batch, made to order by them), whatever the channel | **Maker** (`judgement-lens-maker.md`: their own making cost, their marketplace's matching listings, no supplier read and no first-order gate) |
| anything else: a partial profile (a budget only, print on demand with no channel, channels with no fulfilment) | **General** |
| `goal` side income | **Side income**, on top |
| `goal` brand, or `experience` brand | **Brand**, on top |

When they name both kinds of channel, use the one they say this product will sell through; if that's unclear, use the Marketplace lens and say so in the heading's line. Under $1k with own stock or FBA: the own-stock lens, with the first order as the deciding line, and MOQ-1 suppliers named as the way in.
