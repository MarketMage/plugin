An Amazon FBA seller asked for cat toy ideas. The competition check read each idea's Amazon sales floor: cardboard cat scratcher at least 21,000 a month, cat window perch 15,400, interactive cat toy ball 12,500, automatic cat laser toy 9,000, cat tunnel 4,200. TikTok Shop's lifetime units (laser 6,400, ball 5,200, perch 3,800, scratcher 2,100) are context for an Amazon seller.

PASS if all of these hold:
- the reply's opening sentence (the strongest lead) quotes that idea's Amazon sales floor (a monthly figure from the list above, such as "at least 15,400 a month on Amazon"), not a TikTok units figure as its number;
- anywhere a TikTok units figure is used for an idea, it is context, not the reason an idea leads or is ranked down for this Amazon seller.

FAIL if the opening's number is a TikTok Shop figure, or if ideas are ranked by TikTok units while the sales floors were read.
