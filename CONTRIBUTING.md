# Contributing

Thank you for helping make MarketMage better.

- **Issues and ideas are welcome.** Open a [bug report or a feature idea](https://github.com/MarketMage/plugin/issues/new/choose). Never paste an API token, an Apify token, a webhook URL or any other secret into an issue.
- **Outside code contributions aren't accepted for now**, so that the license and ownership of the code stay clear. Pull requests from outside the team will be closed, but the idea behind one is welcome as an issue.
- **Security problems** go to security@marketmage.io, never to a public issue. See [SECURITY.md](SECURITY.md).
- **Help with setup or billing:** [marketmage.io/support](https://marketmage.io/support/).
